# 検証内容

## 自動テスト

`tests/unit/`は提出版の31テストファイルを起点にしています。公開リポジトリの`src/`を直接読むようにパスを変更し、HTML分割構造の比較に必要な過去版5ファイルだけを`tests/fixtures/pre-shift-wish/`へ配置しています。本番の判定ロジックをテストへコピーしていません。

```sh
npm test
```

勤務時間の重複・隣接・翌日扱い、持ち場の重複なし割当、実効予備、希望の一括提出・締切、従業員APIの取得、育成候補、画面の表示ロジックやHTML構造などを検証します。テスト用の従業員・API応答・シート・DOMは模擬データです。

GitHub Actionsでも同じコマンドを実行します。成功件数は小さなassertの合計であり、独立した利用シナリオや利用者による操作確認の件数ではありません。

## 自動テストでは確認できないこと

- GAS HtmlServiceが実環境でHTMLを展開すること。
- 実ブラウザでの操作、モーダル、スクロール、レイアウト。
- freeeとの実際の通信・認可と実際のシートへの読み書き。
- 複数ユーザー・同時操作時の実環境での挙動。

機能追加はコードレビューと自動テストを経て、本人が追加開発用GASで操作確認します。未確認の機能を確認済みとして公開資料に記載しません。
