# ラーメン店のシフト・マイスター管理

従業員の希望シフトと持ち場別の技能を組み合わせ、ラーメン店の店主が「その時間帯を回せる配置か」を確認するためのWebアプリです。Google Apps Script、Googleスプレッドシート、freee人事労務 public APIを使用しています。

インターンで制作し、2026年9月25日に提出した版を起点に、追加開発の成果を公開する個人ポートフォリオです。freee株式会社の公式製品ではありません。

## 解決したい課題

シフトの人数が足りていても、麺上げや仕込みなどの持ち場を担当できる人が不足すると、お店を回せません。希望を集めて勤務を配置する作業に加え、技能の組み合わせと特定の従業員への依存を確認できるようにしています。

## 現在できること

- 従業員が複数日の希望シフトをまとめて設定・提出する。
- 店主が提出状況と締切後の提出を確認する。
- 希望を見ながら勤務を登録し、勤務と希望を同じ時間軸で確認する。
- 1時間枠ごとに、必要人数と持ち場を重複なく割り当てられるか判定する。
- 不足する人数・持ち場、担当候補、予備人数を確認する。
- マイスター（持ち場別技能）を一括管理し、一人依存や育成候補を確認する。

現時点の従業員選択はデモ用の役割切替です。個人認証と店主専用の権限制御は未実装であり、実際の従業員データを扱う本番運用は想定していません。

## コードを見る

| 場所 | 内容 |
| --- | --- |
| `src/` | GASのサーバー処理、HTML・CSS、画面内JavaScript |
| `tests/unit/` | 本番コードを読み込む自動テスト |
| `tests/fixtures/pre-shift-wish/` | HTML分割構造の比較に必要な過去版の5ファイル |
| `docs/` | 公開向けに整理した企画・技術・検証資料 |

テストはNode.js標準機能で実行でき、追加パッケージのインストールは不要です。

```sh
npm test
```

アプリ本体の実行には、スプレッドシートに紐づいたGAS環境とfreeeの開発用事業所が必要です。`npm test`はブラウザのデモを起動するコマンドではありません。

## 提出版と追加開発

初回公開は2026年9月25日提出版を起点とするコードです。提出後の機能追加はまだありません。ローカルの提出済み版と、追加開発用のスプレッドシート・GASを分離して管理しています。

ログイン、店主専用の編集権限、確定シフトの公開・閲覧、通知などを検討していますが、実装範囲は未決定です。完成した機能は、レビュー・自動テスト・本人のGAS実機確認を経て公開版へ反映します。

## AIとの協働

本人が操作経験や要望を説明し、目的・仕様・実装範囲を決めます。その後、Claude Codeが実装し、Codexがコードとテストをレビューし、本人がGAS実機で確認する流れで開発しています。AIの提案と本人の判断、自動テストの結果と実機確認の結果を区別して記録しています。

このリポジトリには認証情報、接続先ID、実データ、内部の選考資料や会話ログを含めていません。
